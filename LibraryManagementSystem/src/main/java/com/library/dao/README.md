# Library Management System

A robust Java-based application designed to manage library operations efficiently, featuring secure database connectivity and persistent data handling using JDBC and SQL.

## 🚀 Features & Functionality
* **Book Management:** Add, update, delete, and view books in the inventory.
* **Database Integration:** Direct relational database interaction using SQL queries embedded via JDBC PreparedStatements.
* **Modular Architecture:** Organized into clean Data Access Object (DAO), connection management, and execution modules.

## 🛠️ Tech Stack
* **Language:** Java
* **Database / SQL:** Relational Database (JDBC, SQL Queries: `INSERT`, `SELECT`, `UPDATE`, `DELETE`)
* **IDE & Tools:** Eclipse IDE, Git & GitHub

## 📂 Project Structure
* `src/main/java/com/library/dao/BookDAO.java` - Contains data access logic and SQL database queries.
* `src/main/java/com/library/DatabaseConnection.java` - Manages database connectivity settings.
* `src/main/java/com/library/Main.java` - Application entry point.
